# Xparecium

**Reveal how your system works.**

Xparecium is a browser-based system-design simulator for learning,
experimenting, and exploring architectural trade-offs.

Draw your architecture, configure components, and simulate traffic.
See where requests queue, which resources become bottlenecks, and
how design changes affect performance and estimated monthly cloud costs.

Build intuition through experiments:
- Connect servers, databases, caches, queues, and other components.
- Adjust traffic, hardware capacity, and service settings.
- Inspect simulated latency, throughput, and resource utilization.
- Save runs and compare alternative designs.
- Save projects locally and share them through JSON export.

Everything runs in your browser, with no account or application backend.
Results are model-based estimates; no real cloud resources are provisioned.
